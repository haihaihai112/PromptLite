# PromptLite

haihaihai112 的个人文本提示词工作台，面向 Windows 10/11 x64。

## 开始使用

下载 Windows 压缩包，解压完整目录，双击 `PromptLite.exe`。请保留同目录的运行库和 `resources` 文件夹。

第一次打开，点击 **模型设置 → 添加模型**，填写连接名称、接口地址、模型 ID 和 API 密钥。保存后可以测试连接，再返回工作台。

接口采用 OpenAI Chat Completions 兼容协议：

- 云服务示例地址：`https://服务地址/v1`。
- 本地服务示例地址：`http://127.0.0.1:11434/v1`，本地服务可以不填写密钥。
- HTTPS 自定义路径和完整 `/chat/completions` 地址均支持。原生非兼容协议需要额外适配。

优化、迭代、测试和连接检查会调用你配置的模型，费用和数据处理规则由对应服务决定。

## 六项核心功能

1. **优化**：选择系统/用户提示词和通用/精简/结构化策略，输入文本，查看并编辑结果。
2. **迭代**：对当前结果提出修改要求，保存新的完整版本。
3. **前后测试**：在同一模型配置下并排查看原始与优化提示词的回答。
4. **模型设置**：配置多个兼容接口、选择模型、检查连接。
5. **历史记录**：搜索、查看版本、恢复后继续迭代、删除记录。
6. **我的收藏**：保存标题与标签，编辑、搜索和复用常用提示词。

另外支持复制结果、请求取消和 JSON 本地备份。

系统提示词测试时，测试输入作为共同的 user 消息；用户提示词测试时，两侧使用相同 system 上下文和补充材料。模型回答有随机性，界面呈现实际结果，不自动判定优劣。取消、失败、截断或空结果不会保存为成功版本。

## 数据和密钥

本地数据保存在 `%APPDATA%/PromptLite/promptlite.json`。API Key 由 Windows 系统加密能力保护，界面不读取已保存密钥。

**导出备份**不包含密钥。导入会按 ID 合并历史、收藏和模型配置；新导入的模型需要重新填写密钥。现有模型导入时，仅同一接口地址可保留原密钥；地址变化需重新配置。

编辑已有模型时，密钥留空且接口不变会保留密钥；修改接口地址时不会把旧密钥自动转给新地址。删除模型会移除其密钥，但保留历史文本。

不要在应用运行时直接修改数据文件。提示词与输出最长 10 万字，每条历史最多 1,000 个版本，备份最多 20 MiB。系统加密不可用时，应用会阻止密钥保存。

## 从源码运行

需要 Node.js 22.12+ 或 24+、npm，以及 PowerShell 7 (`pwsh`)。

```powershell
npm ci
npm test
npm run build
npm start
```

开发界面与桌面联调：

```powershell
npm run build
npm run desktop:dev
```

只有 `npm run dev` 时为浏览器界面预览；模型和本地存储操作在桌面应用中执行。

生成 Windows 构建：

```powershell
npm run package
```

生成目录：`release/PromptLite-win32-x64/`。默认产物为无需安装的便携目录；首次构建需要下载 Electron 官方运行时。构建不会签名可执行文件。

## 项目结构

```text
src/core/       请求构造与模型客户端
src/shared/     桌面桥接与数据类型
src/components/界面组件
electron/      窗口、桥接、加密与持久化
tests/         领域、接口、来源检查与存储测试
scripts/       开发、构建与打包
docs/          项目设计、实施与验证记录
```

项目源码由本项目独立实现。依赖和 Electron 运行时遵循各自许可证，发布目录保留第三方许可证文件。
