# PromptLite 设计

PromptLite 是 haihaihai112 的个人文本提示词工作台。第一版是中文 Windows 桌面应用，围绕优化、迭代、前后测试、模型配置、历史和收藏六项功能。

工作台显示原始提示词和可编辑优化结果，选择系统或用户提示词、通用或精简或结构化策略；支持流式显示与取消。优化和迭代成功后保存版本链，失败和取消不保存为成功。模型请求固定启动时的输入快照。恢复历史时能够查看任意版本并继续迭代。

测试保持模型和参数一致：system 类型用同一用户测试输入测试两个 system 提示词；user 类型用同一 system 上下文和补充材料测试两个 user 提示词。分别展示两侧内容与错误，不自动评分，不承诺一次测试证明效果。

模型配置采用 OpenAI Chat Completions 兼容协议，支持 HTTPS 自定义服务及 HTTP 本地服务。密钥只在主进程处理，通过 Windows 加密能力保存在新应用自己的 userData 目录，前端只知道是否已设置密钥。历史和收藏在本地保存，JSON 备份合并导入但不包含密钥。

结构：Vue 3 + TypeScript + Vite 渲染层，Electron 主进程提供明确 IPC 方法，领域层构造请求，模型客户端负责 SSE 和取消，存储层负责验证及原子写入。各层接口见 src/shared/contracts.ts。开启隔离与沙箱，禁止渲染进程直接访问 Node，拒绝非主窗口 IPC。

视觉：冷灰蓝底色 #f3f6fb、纸白 #ffffff、深蓝 #172c4c、蓝色操作 #325fdb、灰色辅助 #697991；Segoe UI 与 Microsoft YaHei UI 承担中文交互，Consolas 仅用于模型 ID。左侧窄导航，右侧一对宽编辑区域，测试面板按需展开。减少装饰性面板，让文本成为视觉中心。键盘焦点清楚，窄窗口可切换纵向布局。

验收：Windows 能启动；六项流程连通；取消、鉴权、空结果和网络错误可理解；持久化重启不丢失；备份不含密钥；领域、接口和存储测试通过；完成真实 Electron 交互和截图检查。真实服务质量与兼容性需要用户配置接口后确认。
