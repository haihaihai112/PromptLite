## 验证边界

模型请求使用本机 HTTP 测试服务，提供确定性 SSE、单侧失败、鉴权失败和慢速响应，用于验证应用流程。该服务及其测试数据未打包进产品。未使用用户的真实 API Key，也未验证商业模型服务的实际优化质量或所有兼容接口。

备份检查通过真实界面按钮、IPC 和文件读写执行；测试预设了系统文件对话框的选择结果，未自动操作 Windows 原生文件选择界面。

可执行文件未签名；仅验证当前 Windows x64 环境。第三方运行时与依赖的许可证保留在发布目录和 THIRD_PARTY_NOTICES.md 中。
